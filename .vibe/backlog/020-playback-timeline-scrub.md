# Timeline playback controls (play, pause, scrub)

## Description
Animated and parallax stages can only be seen live. Add play/pause/step and a tick scrubber so an author can inspect any moment of the stage's animation.

## Acceptance Criteria
- [ ] Play/pause, single step and speed controls
- [ ] Scrubbing to tick N shows the layer state for that tick
- [ ] Keyboard shortcuts via the shared ShortcutManager
