# Module: input
**Role:** The stage folder input — gathers files from a folder selection or drag-and-drop, picks the `.def` candidate (auto or user-selected), loads it through the WASM bridge, and resolves its referenced sprite sheet from the same folder by basename; also renders the folder-picker + drag-and-drop UI on top of that logic. Per backlog item 006, also resolves an optional 3D model-based stage's referenced model/`.hdr` files the same way, but never blocks the overall load on failure — see `model-assets.ts`.
**Files:** `src/input/folder-entries.ts`, `src/input/basename-resolution.ts`, `src/input/file-bytes.ts`, `src/input/stage-file-input.ts`, `src/input/stage-file-input-view.ts`, `src/input/model-assets.ts`
**Exports:** `filesFromWebkitDirectoryFiles(files): GatheredFile[]`, `filesFromDataTransferItems(items): Promise<GatheredFile[]>`, `collectFilesFromEntry(entry): Promise<GatheredFile[]>`, `GatheredFile`, `resolveFileByBasename(referencedPath, files): BasenameResolution`, `readFileAsBytes(file): Promise<Uint8Array>`, `resolveCandidates(files): CandidateResolution`, `resolveSpriteSheet(referencedSpriteFile, files): SpriteSheetResolution` (thin wrapper over `resolveFileByBasename`), `resolveModelAssets(stage, files, options?): Promise<ModelAssetsResolution>`, `loadStageFromFolderFiles(files, options?): Promise<StageFolderInputResult>`, `loadStageFromChosenEntry(entry, files, options?): Promise<StageFolderInputResult>`, `StageFolderInputOptions`, `StageFolderInputResult` (now including `modelAssets`), `renderStageFileInput(root, options): void`
**Depends on:** `modules/wasm.md`
