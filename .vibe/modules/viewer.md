# Module: viewer
**Role:** The screens that show what was loaded. The characteristics panel displays the loaded stage's name, author, camera bounds, and stage boundaries. The BG element browser + background preview lists every configured BG element next to a composed canvas preview, drawn in layer order, with per-element selection highlighting, a placeholder for a sprite reference that doesn't resolve, and time-based playback (parallax scroll + animated element frame cycling) via a Play/Pause control. Per backlog item 006, when the loaded stage has 3D model data, `background-preview.ts` also mounts a `three`-rendered model layer (via `model-preview.ts`) behind its own canvas (made transparent in that mode) plus a persistent mode badge — see `.vibe/decisions/005`. Per backlog item 008, `background-preview.ts` and `model-preview.ts` each collect small "re-translate this in place" closures as they build their DOM (badge, status line, Play/Pause label, every row's summary/status text, a failure banner's body) and fire them from their own `onLocaleChange` subscription on a live language switch — playback position, selection, and the mounted `three` renderer are left untouched, unlike the characteristics panel's plain full re-render.
