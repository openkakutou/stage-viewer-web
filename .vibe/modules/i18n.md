# Module: i18n
**Role:** This app's own localization setup (backlog item 008). Wires the shared `@openkakutou/web-ui-kit` i18next integration layer under this app's own namespace and `localStorage` key, plus a `t(key, defaultValue, vars?)` wrapper every other module calls through — falls back to the interpolated `defaultValue` verbatim whenever `initAppI18n` hasn't resolved yet in the current page/test.
**Files:** `src/i18n/i18n.ts`, `src/i18n/en.json`, `src/i18n/fr.json`
**Exports:** `initAppI18n(): Promise<I18nInstance>`, `t(key: string, defaultValue: string, vars?: Record<string, string>): string`, `onLocaleChange(callback: () => void): () => void`, `getI18n(): I18nInstance | undefined`, `NAMESPACE: string`
**Depends on:** `@openkakutou/web-ui-kit` (npm, `initI18n`/`getI18n`/`onLocaleChange` re-exported from its own i18n integration layer)
